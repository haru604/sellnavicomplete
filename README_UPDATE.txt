セルナビ v10 更新内容

1. LINE共有
- 「数字だけ最新化」「基本文を再生成」ボタンを削除
- 実績保存時・LINE画面表示時に数字を自動最新化
- 手動で追加した文章・改行は保持

2. 入力ガイド
- 各項目に「入力ガイド」を追加
- サポート定額：現在の合計実績 ＋ 当日の獲得件数を入力
- 有償サポート：現在の合計実績 ＋ 当日の獲得金額を入力
- +1Collection：POSで確認した最新の実績金額を入力
- その他：13時以降にセルナビで更新された最新実績を入力

3. 複数端末同期（Supabase）
- 設定画面から Project URL / Publishable Key / 店舗コードを登録
- 最初だけ最新端末で「この端末を親にする」
- 古い端末は「クラウドから受け取る」
- 以後は保存時アップロード＋15秒間隔/復帰時に受信

Supabase側では SUPABASE_SETUP.sql をSQL Editorで1回実行してください。
